# VLM Visual Check Protocol

生成した SVG/PNG に対して VLM が画像を確認する際の標準チェックリストです。

**運用ルール**:
- 生成後に必ずこのチェックリストを実行する
- 各項目は `PASS / FAIL / SKIP(意図的)` で答える
- FAIL が 1 件でもあれば最終判定は REWORK
- SKIP は「デザイン的に意図的」と明示できる場合のみ使用

---

## 1. テキスト配置チェック

| # | 質問 | 期待値 |
|---|---|---|
| T-01 | 各テキスト要素の**上端**が切れていますか？ | NO |
| T-02 | 各テキスト要素の**下端**が切れていますか？ | NO |
| T-03 | 各テキスト要素の**左端**が切れていますか？ | NO |
| T-04 | 各テキスト要素の**右端**が切れていますか？ | NO |
| T-05 | テキストは意図した領域（ボタン本体など）の**内側**にありますか？ | YES |

---

## 2. 視認性チェック

| # | 質問 | 期待値 |
|---|---|---|
| V-01 | テキストと背景のコントラストは十分ですか？（読みやすいか） | YES |
| V-02 | テキストが他のレイヤー（ハイライト等）に**埋もれて**いますか？ | NO |
| V-03 | テキストの文字が識別可能ですか？（フォントサイズが十分か） | YES |

---

## 3. レイアウトチェック

| # | 質問 | 期待値 |
|---|---|---|
| L-01 | 要素が viewBox **外**にはみ出していますか？ | NO |
| L-02 | 意図しない**白い余白**や**透明領域**が大きくありますか？ | NO |
| L-03 | 全体のバランスは用途（usage_scope）に合っていますか？ | YES |

---

## 4. 用途適合チェック（Human Gate AG-3 相当）

| # | 質問 | 期待値 |
|---|---|---|
| U-01 | このボタンは `primary` の強さ（目立ち）がありますか？ | YES |
| U-02 | 小サイズ（64x64 等）に縮小しても判別できますか？ | YES |

---

## 判定ルール

```
全項目 PASS / SKIP(意図的) → 最終判定: PASS
FAIL 1件以上              → 最終判定: REWORK（失敗項目を列挙）
判定不能                  → 最終判定: STOP（理由を記述）
```

---

## SKIP の記録形式

デザイン的に意図的な場合は以下の形式で記録すること。

```
T-01: SKIP
理由: タイトルロゴのデザインで意図的に上部クロップを使用
```
