# デザイナー向けワークフローガイド

このガイドでは、デザイナーがUI Studioを使用してUI素材を生成・編集・保存する流れを説明します。

## 前提知識

- **プログラミング不要**: ブラウザ上で完結します
- **自然言語で指示**: プロンプトを日本語で記述できます
- **編集可能な素材**: 生成されたSVGはIllustratorやInkscapeで編集可能です

## セットアップ

### 1. Studio UIの起動

プロジェクトルートで以下を実行：

```bash
./Start\ Studio.command
```

ブラウザで `http://127.0.0.1:8000/studio.html` が自動的に開きます。

### 2. AI設定（初回のみ）

AI生成を使用する場合、AI設定パネルで以下を設定：

1. **AI生成を有効化** チェックボックスをON
2. **プロバイダー** を選択（OpenAI または Gemini）
3. **APIキー** を入力（ブラウザに保存されます）
4. **モデル** を選択（デフォルトのままでOK）

> **注意**: APIキーは管理者から取得してください。

## 基本ワークフロー

### ステップ1: プロンプト入力

プロンプト入力欄に、作りたいUI素材の世界観や意図を記述します。

**良いプロンプトの例：**
- ✅ "神殿風の発光ボタン"
- ✅ "タブバー、未読バッジ付き"
- ✅ "モーダルで確認ダイアログ"
- ✅ "トースト通知、成功表示"
- ✅ "HPバー、赤いグラデーション"

**避けるべきプロンプト：**
- ❌ "ボタン"（抽象的すぎる）
- ❌ "何か通知"（意図が不明確）
- ❌ "いい感じのUI"（曖昧すぎる）

### ステップ2: 素材を生成

「素材を生成」ボタンをクリックします。

- AI生成が有効な場合: AIがプロンプトを解釈してJSON生成
- AI生成が無効な場合: テンプレートから自動選択

生成されると、右側のプレビューエリアにSVGが表示されます。

### ステップ3: 差分修正（オプション）

生成結果が意図と異なる場合、差分修正パネルで修正できます：

1. 差分修正パネルを展開
2. 修正指示入力欄に自然言語で指示を記述
3. 「修正を適用」ボタンをクリック

**修正指示の例：**
- "ボタンをもっと強調して"
- "色を暗くして"
- "サイズを大きくして"
- "グラデーションを追加して"

### ステップ4: 保存

満足のいく結果が得られたら、保存します：

1. **保存名** を入力（例: `button_temple_glow.json`）
2. **tags** を入力（例: `action, primary, fx_glow`）
3. 「Repoに保存」ボタンをクリック

保存されたファイルは `generated/` ディレクトリに配置されます。

### ステップ5: SVG書き出し

保存したJSONファイルからSVGを書き出すには、CLIを使用します：

```bash
python -m src.cli examples/button_sf.json -o output.svg
```

または、Studio UIの「JSONを保存」ボタンでJSONをダウンロードし、後でCLIで変換できます。

## 便利な機能

### クイックプロンプト

よく使うプロンプトはチップとして用意されています。クリックするだけで入力欄に反映されます。

### 選定結果の確認

生成後、「選定結果」セクションで以下を確認できます：

- 選択されたテンプレート
- マッチしたキーワード
- テンプレートの意図（intent）
- 使用例（when）

これを参考に、次回のプロンプト作成に活かせます。

### ゲージ形状の調整

ゲージ系のUI素材（HPバー、XPバーなど）は、ゲージ形状エディタで微調整できます：

- **shape_profile**: radial / segmented / polygon
- **sides**: 多角形の辺数
- **segment_count**: セグメント数
- **thickness**: 太さ

### 制約の編集

constraint_flags と constraint_params を編集して、制約を調整できます：

- **safe_area**: セーフエリア内に配置
- **min_tap**: 最小タップ領域を確保
- **max_width**: 最大幅を制限

## トラブルシューティング

### 生成が失敗する

**症状**: 「素材を生成」ボタンをクリックしても何も表示されない

**原因と解決策**:
1. **AI設定が不正**: APIキーを確認
2. **プロンプトが不適切**: より具体的に記述
3. **ネットワークエラー**: ブラウザのコンソールを確認

### 意図と異なる結果が生成される

**症状**: 生成されたUI素材が期待と異なる

**解決策**:
1. プロンプトをより具体的に記述
2. 差分修正機能を使用
3. 選定結果を確認し、適切なテンプレートが選ばれているか確認

### 保存できない

**症状**: 「Repoに保存」ボタンをクリックしてもエラーが出る

**原因と解決策**:
1. **ファイル名が不正**: 英数字とアンダースコアのみ使用
2. **tagsが不正**: カンマ区切りで記述
3. **JSONが無効**: 生成JSONを確認

## ベストプラクティス

### プロンプトの書き方

1. **世界観を明確に**
   - "神殿風"、"SF風"、"ファンタジー風" など

2. **機能を具体的に**
   - "発光"、"グラデーション"、"影付き" など

3. **既存テンプレートを参考に**
   - 選定結果の`intent`や`when`を確認

### タグの付け方

タグは以下のカテゴリから選びます：

- **role**: action, navigation, container, data_display, feedback
- **importance**: primary, secondary, info
- **state**: default, hover, pressed, disabled
- **constraints**: safe_area, min_tap
- **fx_tags**: fx_glow, fx_shadow

### ファイル命名規則

- 小文字とアンダースコアを使用
- 意味のある名前を付ける
- 日付を含める（オプション）

**例:**
- `button_temple_glow_20260119.json`
- `tab_bar_badge_20260119.json`
- `modal_confirm_20260119.json`

## よくある質問

### Q: AI生成とテンプレート選択の違いは？

**A**: 
- **AI生成**: プロンプトを解釈して新しいJSONを生成。より柔軟だが、APIキーが必要。
- **テンプレート選択**: 既存のテンプレートから最適なものを選択。APIキー不要。

### Q: 生成されたSVGを編集できますか？

**A**: はい。IllustratorやInkscapeで開いて編集できます。ただし、JSONを再生成すると編集内容は失われます。

### Q: 複数のUI素材を一度に生成できますか？

**A**: 現在は1つずつ生成する必要があります。バッチ生成機能は将来追加予定です。

### Q: 生成したUI素材を他のプロジェクトで使えますか？

**A**: はい。JSONファイルとSVGファイルは自由に使用できます。

### Q: APIキーの費用は？

**A**: OpenAIとGeminiは従量課金制です。詳細は管理者に確認してください。
